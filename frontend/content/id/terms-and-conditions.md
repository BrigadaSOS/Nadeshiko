**Terakhir diperbarui: 14 Agustus 2026**

Harap baca syarat dan ketentuan ini dengan saksama sebelum menggunakan situs web Nadeshiko.

## Hanya untuk Penggunaan Pendidikan dan Pribadi

Konten yang disediakan oleh Nadeshiko hanya ditujukan untuk penggunaan pendidikan dan pribadi. Anda setuju untuk menggunakan konten semata-mata untuk keperluan pendidikan Anda sendiri dan bukan untuk penggunaan komersial apa pun. Konten yang tersedia pada layanan disediakan "sebagaimana adanya" dan "sebagaimana tersedia", dan Nadeshiko tidak memiliki atau mengklaim kepemilikan atas konten tersebut kecuali dinyatakan secara tegas sebaliknya.

## Hak Cipta dan Kepatuhan terhadap DMCA

Nadeshiko menghormati hak kekayaan intelektual pihak lain dan mengharapkan pengguna layanan melakukan hal yang sama. Kami mematuhi Digital Millennium Copyright Act (DMCA) dan akan menanggapi pemberitahuan dugaan pelanggaran hak cipta yang memenuhi persyaratan DMCA dan hukum lain yang berlaku.

Untuk informasi terperinci tentang kebijakan DMCA kami, termasuk cara mengajukan pemberitahuan permintaan penghapusan konten, silakan lihat halaman [Kebijakan DMCA](/dmca) kami.

## Akses API

Jika Anda diberi akses API, Anda setuju untuk menggunakan API sesuai dengan ketentuan ini dan ketentuan tambahan yang disertakan bersama kunci API Anda. Penggunaan API oleh Anda tunduk pada ketentuan berikut:

- **Kunci API**: Anda harus menggunakan kunci API valid yang diberikan kepada Anda oleh Nadeshiko. Anda bertanggung jawab menjaga keamanan kunci API Anda dan atas setiap penggunaan kunci tersebut, baik yang diizinkan maupun tidak.
- **Batas Frekuensi Permintaan**: Anda setuju untuk mematuhi setiap batas frekuensi permintaan atau pembatasan penggunaan yang diberlakukan oleh Nadeshiko. Kegagalan mematuhi batas tersebut dapat mengakibatkan penangguhan atau penghentian akses API Anda.
- **Aktivitas yang Dilarang**: Anda tidak boleh menggunakan API untuk melakukan aktivitas apa pun yang melanggar ketentuan ini atau hukum maupun peraturan yang berlaku. Aktivitas yang dilarang mencakup, tetapi tidak terbatas pada, pengambilan data otomatis (scraping), akses data tanpa izin, dan segala bentuk penyalahgunaan atau penggunaan API yang tidak semestinya.
- **Penggunaan Data**: Data apa pun yang diakses melalui API hanya untuk penggunaan pribadi atau pendidikan Anda. Anda tidak boleh membagikan, menjual, atau mendistribusikan data tersebut kepada pihak ketiga tanpa izin tegas dari Nadeshiko.
- **Perubahan**: Nadeshiko berhak mengubah, menangguhkan, atau menghentikan API kapan saja, dengan atau tanpa pemberitahuan. Nadeshiko tidak akan bertanggung jawab kepada Anda atau pihak ketiga mana pun atas perubahan, penangguhan, atau penghentian API.

## Integrasi Pihak Ketiga

Aplikasi pihak ketiga dapat membaca konten Nadeshiko atas nama pembaca, asalkan setiap pembaca menggunakan kunci API miliknya sendiri dan aplikasi tersebut memenuhi semua ketentuan di bawah ini. Pemenuhan ketentuan tersebut **merupakan** izin tegas yang disyaratkan oleh ketentuan Penggunaan Data di atas; integrasi yang memenuhinya tidak perlu meminta izin terpisah kepada kami.

- **Kunci milik pembaca sendiri**: aplikasi harus menggunakan kunci yang dibuat sendiri oleh pembaca dan dapat dicabut oleh pembaca kapan saja. Aplikasi tidak boleh menyertakan kunci bersama, menggabungkan beberapa pembaca dalam satu kunci, atau mengirim kunci pembaca ke server aplikasi itu sendiri.
- **Cakupan akses hanya baca**: mintalah pembaca memberikan kunci yang terbatas pada cakupan akses `READ_MEDIA`. Agar dapat berfungsi, integrasi tidak boleh mewajibkan cakupan akses yang dapat menulis ke profil, aktivitas, atau koleksi pembaca.
- **Permintaan langsung**: permintaan harus dikirim dari klien milik pembaca sendiri langsung ke Nadeshiko. Aplikasi tidak boleh meneruskan permintaan melalui proksi, menyimpan respons setelah sesi pembaca berakhir, membuat salinan cermin atau indeks korpus, menerbitkannya ulang, atau menggunakannya untuk melatih model.
- **Kuota**: kuota dan batas frekuensi permintaan milik pembaca sendiri berlaku. Tangani respons `429` dan jangan mengakali batas tersebut.
- **Klasifikasi konten**: setiap segmen memiliki `contentRating`. Aplikasi bertanggung jawab memfilter atau menampilkan klasifikasi yang sesuai untuk penggunanya — permintaan yang tidak menyertakan filter klasifikasi konten akan menerima semua klasifikasi, termasuk `EXPLICIT`.
- **Atribusi**: sebutkan Nadeshiko sebagai sumber konten, serta sertakan tautan ke ketentuan ini dan [Kebijakan DMCA](/dmca) kami.

Kami dapat mencabut izin ini dari aplikasi mana pun kapan saja. Bagian Penghentian dan Penafian di bawah berlaku bagi aplikasi sebagaimana berlaku bagi pembaca.

## Penafian

Penggunaan layanan sepenuhnya menjadi risiko Anda sendiri. Layanan disediakan atas dasar "SEBAGAIMANA ADANYA" dan "SEBAGAIMANA TERSEDIA". Layanan disediakan tanpa jaminan apa pun, baik tersurat maupun tersirat, termasuk, tetapi tidak terbatas pada, jaminan tersirat mengenai kelayakan untuk diperdagangkan, kesesuaian untuk tujuan tertentu, tidak adanya pelanggaran hak, atau praktik pelaksanaan kewajiban (course of performance).

Nadeshiko tidak menjamin bahwa:

- Layanan akan berfungsi tanpa gangguan, aman, atau tersedia pada waktu atau lokasi tertentu
- Setiap kesalahan atau cacat akan diperbaiki
- Layanan bebas dari virus atau komponen berbahaya lainnya
- Hasil penggunaan layanan akan memenuhi kebutuhan Anda
